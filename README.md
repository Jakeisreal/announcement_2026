## ⚙️ GitHub Pages 배포 활성화 방법 (최초 1회)

1. 저장소 상단 메뉴에서 **Settings** 클릭
2. 좌측 사이드바에서 **Pages** 클릭
3. **Build and deployment** 항목의 **Source**를 `Deploy from a branch`로 선택
4. **Branch**를 `main` / `/ (root)` 로 선택 후 **Save** 클릭
5. 약 1분 후 `https://jakeisreal.github.io/announcement_2026/` 주소로 전 세계 어디서나 모바일 및 PC로 즉시 접속 가능합니다.
